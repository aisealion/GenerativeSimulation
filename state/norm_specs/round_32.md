# Round 32 Norm Specification

## Policy Summary (as defined in `norm.txt`)
- **Per‑trip catch cap**: 1.5 kg.
- **Mandatory deposit**: 0.4 kg of every trip’s catch must be deposited into the communal pool.
- **Lake preservation**: After any trip the lake must retain at least 20 % of its current stock (i.e., total raw catch for the day may not exceed 80 % of `stock_before`).
- **Community‑wide catch limit**: The sum of kept catch for the day may not exceed 70 % of the lake’s stock.
- **Violation handling**: If any constraint is breached, the fisher receives no fish for that trip and a sanction is recorded. When the lake‑preservation limit is hit, fishing for the remainder of the day is halted.

## Implementation Overview (`norms/round_32.py`)
- **Class**: `Round32Norm` (subclass of `engine.norms.base.Norm`).
- **Type name**: `"round_32"` – used by the registry to discover the norm.

  - `raw_total` – cumulative raw catch for the day.

  - `deposits` – list of deposit amounts for the day.
  - `halt` – flag set when the lake‑preservation limit is reached, signalling that further trips should be stopped.
- **Norm‑state data** (persistent across rounds):
  - `reserve_kg` – total communal reserve kilograms.

## Detailed Hook Logic
### `evaluate`
1. **Lake‑preservation check**: If `raw_total + raw_kg > 0.8 * stock_before`, set `halt` flag and return a `NormDecision.violation` with sanction `"stock_limit"` and a note indicating fishing is halted.
2. **Per‑trip cap & deposit**:
   - Apply cap: `capped = min(raw_kg, 1.5)`.
   - Require deposit of `0.4 kg`. If `capped < 0.4`, record a zero deposit and return a `violation` with sanction `"deposit_failed"`.
   - Compute kept amount: `kept = capped - 0.4`.
3. **Community‑wide keep limit**: If `kept_total + kept > 0.7 * stock_before`, record a zero deposit and return a `violation` with sanction `"community_limit"`.
4. **Successful case**: Record the deposit, update `raw_total` and `kept_total`, and return `NormDecision.adjust` with the kept amount. If the original `raw_kg` exceeded the per‑trip cap, a note `"capped at 1.5 kg per policy"` is attached.

### `on_round_end`
- Sum all deposits from the round scratch and add them to the persistent `reserve_kg` stored via `context.norm_state(self.key)`. Clear the round‑scratch dictionary to avoid leakage into the next round.

## Interaction with Other Norms
- This norm is intended to be the **first** norm in the configuration order for round 32 because it enforces the base policy constraints. Subsequent norms (if any) will receive the adjusted `kept_kg` and can add further rules.
- The `halt` flag is stored in round‑scratch; other norms may read it to short‑circuit their own logic, but the core engine already stops further trips when `NormEngine.is_eligible` returns `False`. Implementers may add a guard in later norms:
  ```python
  if context.round_scratch(self.key).get("halt"):
      return NormDecision.violation(kept_kg=0.0, sanction="halted", note="fishing halted for the day")
  ```
